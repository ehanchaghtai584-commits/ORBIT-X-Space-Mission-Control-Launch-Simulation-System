# ORBIT-X-Space-Mission-Control-Launch-Simulation-System
ORBIT-X is a C-based space mission control simulator featuring spacecraft diagnostics, GO/NO-GO launch decisions, countdown, flight telemetry, emergency handling, Safe Mode, fault recovery, and orbit insertion. Built to demonstrate programming logic through interactive space exploration.



**ORBIT-X** is an interactive, console-based space mission simulation system developed using **C programming**. Inspired by real-world space mission operations, the project demonstrates how programming logic can be used to simulate spacecraft launches, monitor critical systems, and make mission-control decisions.

Unlike traditional beginner-level management systems, ORBIT-X focuses on **engineering simulations, decision-making algorithms, and emergency response mechanisms**.

### Key Features

- **Mission Configuration:** Set mission details, spacecraft name, commander, target altitude, fuel, and payload.
- **Pre-Launch Diagnostics:** Evaluate engine, navigation, communication, power, and flight-control systems.
- **GO/NO-GO Decision System:** Automatically determine launch readiness based on system health, weather, fuel, and payload conditions.
- **Launch Simulation:** Experience a countdown, ignition, liftoff, ascent, stage separation, and orbit insertion.
- **Flight Telemetry:** Monitor simulated altitude, velocity, fuel consumption, and battery levels.
- **Emergency Management:** Simulate system failures, activate Safe Mode, attempt recovery, or abort the mission.
- **Mission Reporting:** Generate a summary of mission performance, system faults, recoveries, and final mission status.
- **Input Validation:** Handle invalid inputs and prevent incorrect mission operations.

### Technologies & Concepts

**Language:** C

**Concepts:** Functions, conditional statements, loops, strings, arrays, flags, modular programming, and input validation.

### Project Objective

The goal of ORBIT-X is to demonstrate how fundamental C programming concepts can be combined to build an interactive simulation that models complex decision-making processes.

**Note:** ORBIT-X is an educational simulator using simplified physics and predefined mission parameters. It is not real spacecraft flight-control software.
